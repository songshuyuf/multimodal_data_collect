# VR 同步测试步骤

## 一、准备材料

1. **一段视频**：任意 MP4 文件（建议 10–30 秒用于快速测试）
2. **PC**：运行本项目的电脑
3. **PICO**：与 PC 在同一 WiFi 下

---

## 二、把视频拷到 PICO

1. 用 **USB 数据线** 连接 PICO 和 PC
2. PICO 上选择「文件传输」模式
3. 在 PC 上打开 PICO 的存储盘（类似 U 盘）
4. 新建文件夹，例如 `vr_test`
5. 把视频拷进去，并重命名为 `video.mp4`（或保持原名，后面在页面里改）

---

## 三、把 HTML 页面拷到 PICO

1. 打开项目里的 `vr_resources/pico_vr_page.html`
2. **先改 PC IP**：把 `192.168.1.100` 改成你 PC 的局域网 IP
   - 查 PC IP：在 PC 上打开 CMD，输入 `ipconfig`，看「IPv4 地址」（如 192.168.1.105）
3. 保存后，把 `pico_vr_page.html` 拷到 PICO 的 `vr_test` 文件夹（和视频同一目录）

---

## 四、在 PC 上启动同步服务

1. 打开终端，进入项目目录：
   ```
   cd d:\python\pythonProject\Ai_art_treat
   ```

2. 运行单元测试（会启动服务并做一次自检）：
   ```
   python -X utf8 tests/test_vr_unit.py --simulate
   ```
   - 运行后终端会显示 `PICO 连接地址: http://你的IP:8765/state`
   - **不要关这个窗口**，服务会一直跑

3. 或者只启动服务、不跑测试：
   ```
   python -c "
   from core.vr_sync import VRSyncServer
   s = VRSyncServer(port=8765)
   s.start()
   print('服务已启动，按 Ctrl+C 停止')
   import time
   while True:
       time.sleep(1)
   "
   ```

---

## 五、在 PICO 上打开页面

1. 戴上 PICO，打开 **内置浏览器**
2. 在地址栏输入（根据你实际路径改）：
   ```
   file:///sdcard/vr_test/pico_vr_page.html
   ```
   - 路径取决于你把文件放在哪，可在 PICO 的「文件管理」里确认
3. 打开后，页面会显示「等待连接 PC...」或「轮询 PC...」

---

## 六、测试同步

1. **PC 端**：在项目目录新开一个终端，执行：
   ```
   python -c "
   import requests
   import time
   # 发 play
   r = requests.get('http://127.0.0.1:8765/state')
   print('当前:', r.json())
   # 需要先启动服务，再手动 set_state，这里用 curl 或另写脚本
   "
   ```
   更简单的方式：用浏览器访问 `http://你的PC的IP:8765/state`，会看到 `{"cmd":"idle"}`

2. **发 play 命令**：需要写个小脚本，或先跑下面的「完整测试脚本」

---

## 七、完整测试脚本（推荐）

在 PC 上新建 `test_vr_manual.py`，放在项目根目录：

```python
# test_vr_manual.py - 手动测试 VR 同步
import time
import sys
sys.path.insert(0, '.')

from core.vr_sync import VRSyncServer, get_local_ip

server = VRSyncServer(port=8765)
server.start()

print(f"\n服务已启动！")
print(f"PICO 浏览器打开: file:///sdcard/vr_test/pico_vr_page.html")
print(f"确保 HTML 里的 PC_IP 已改为: {get_local_ip()}\n")
print("5 秒后发送 play...")
time.sleep(5)

server.set_state("play")
print("已发送 play，PICO 应开始播放")
print("10 秒后发送 stop...")
time.sleep(10)

server.set_state("stop")
print("已发送 stop，PICO 应停止")
time.sleep(2)

server.stop()
print("服务已关闭")
```

运行：
```
python test_vr_manual.py
```

**操作顺序**：先运行脚本 → 在 PICO 上打开页面 → 等 5 秒，PICO 应自动开始播放 → 约 10 秒后自动停止。

## 八、常见问题

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| PICO 显示「连接 PC 失败」 | PC IP 填错、不在同一 WiFi、PC 防火墙拦截 | 检查 IP、关闭防火墙或放行 8765 端口 |
| 页面打不开 | 路径写错 | 用 PICO 文件管理找到文件，长按看路径 |
| 视频不播 | 视频路径错、格式不支持 | 用 MP4，和 HTML 放同一目录，命名为 video.mp4 |
| 改了 HTML 但没生效 | 浏览器缓存 | 刷新或重新打开页面 |

---

## 九、快速自检（不连 PICO）

只测 PC 端服务是否正常：

```
python -X utf8 tests/test_vr_unit.py
```

看到 `[PASS] 全部通过` 即表示服务正常。
