# Shimmer GSR+ LSL Integration - 项目总结

## 项目概述

本项目为Shimmer GSR+外周生理信号采集设备开发了完整的Lab Streaming Layer (LSL)集成方案,支持多模态数据同步采集。

## 核心功能

### ✅ 已实现功能

1. **设备连接管理**
   - 蓝牙自动连接
   - 设备配置和初始化
   - 错误处理和重连机制

2. **实时数据采集**
   - GSR(皮肤电反应)信号
   - PPG(光电容积脉搏波)信号
   - 加速度计数据(可选)
   - 电池电压监控
   - 可配置采样率(51.2-512 Hz)

3. **LSL流集成**
   - 创建标准LSL outlet
   - 实时数据推送
   - 完整的流元数据
   - 时间戳同步

4. **数据保存**
   - CSV格式输出
   - 会话元数据记录
   - 缓冲写入优化
   - 统计信息追踪

5. **工具和测试**
   - 设备扫描工具
   - LSL接收器测试
   - 模块化测试脚本
   - 自动化安装脚本

## 已知限制

1. **蓝牙连接**
   - 依赖系统蓝牙驱动
   - 可能受距离和干扰影响
   - Windows配对过程较复杂

2. **数据格式**
   - 当前仅支持CSV
   - HDF5待实现
   - 实时查看需额外工具

3. **平台差异**
   - macOS串口配置较复杂
   - Linux需要权限设置
   - 各平台COM口命名不同

## 故障排查

### 常见问题及解决方案

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 连接失败 | 未配对/端口错误 | 运行scan_devices.py |
| 找不到LSL流 | 防火墙/网络问题 | 检查防火墙设置 |
| 数据率低 | 蓝牙干扰 | 靠近设备/减少干扰 |
| 导入错误 | 缺少依赖 | 运行setup.py |
